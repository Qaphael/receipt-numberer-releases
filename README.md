# Receipt Numberer - downloads

Built installers of [Receipt Numberer](https://github.com/Qaphael/receipt-numberer),
published automatically when a version tag is pushed to the source repository.

- `ReceiptNumberer-Setup-<version>.exe` - the Windows installer (recommended)
- `ReceiptNumberer-<version>-portable.zip` - the portable build, extract anywhere
- `SHA256SUMS.txt` - checksums of the two files above

The app checks this page once at launch and updates itself from it. Nothing
else lives in this repository - the source stays private.
